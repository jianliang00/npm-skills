# Agents

This file provides guidance for AI coding agents working on this repository.

## Contributing Guidelines

Please refer to [CONTRIBUTING.md](./CONTRIBUTING.md) for project conventions, including the **commit message convention** that must be followed for all commits.

## Project Overview

npm-skills converts npm packages into installable AI agent skills. The main entry point is `bin/npm-skills.js`, and the core logic lives in `src/`.

## Testing

Run the test suite with:

```bash
npm test
```
